关于这本书的「鲜活化」

这不是又一本电子书，而是一个 AI Agent 编排的可互动动画书。我们用海明威的中篇小说《老人与海》做 MVP，把一个具体的"读经典名著"小场景做透。

核心问题

经典文学在年轻一代里被遗忘，不是因为文字不好，而是阅读方式太单薄。CastReader、NotebookLM 等 AI 工具能"听书"或"看视频"，但读者仍然是被动接受者。

我们的差异化

  • 可对话：随时停下和圣地亚哥聊——他用原文说话，不是空泛的 LLM 扮演。
  • 可参与：两个关键抉择点，读者不再是旁观者。
  • 可感：每幕一张电影感插画 + Web Speech API 朗读 + 名言高亮。
  • 经典公版：没有版权风险，可任意扩展到《百年孤独》《卡拉马佐夫兄弟》等。

Agent 流程编排

① 书籍解析层　docx / txt → LLM 生成书名 / 简介 / 锚点 / 章节摘要
② 场景生成层　锚点人物+场景 → MiniMax ImageGen 生成一致插画
③ 角色 Agent　人设 System Prompt + 5 幕原文检索(RAG) → 回复
④ 互动编排　预设话题 + 决策点 → 引导用户回到叙事
⑤ 朗读 Agent　MiniMax T2A 语音（未配置时降级 Web Speech）

技术栈

纯前端：HTML + CSS + 原生 JS，无构建步骤。封面是一个书架，《老人与海》为可读样书，其余为"制作中"占位。对话采用预设话题 + 自定义输入：预设自带提前生成的插图；自定义输入在配置 MiniMax 图片密钥后实时生成插图，并用书籍锚点保证人物 / 场景前后一致。

按 Ctrl+Shift+D 打开开发者模式，配置 MiniMax 图片 / 语音密钥与 LLM（OpenAI 兼容）。所有密钥仅存本地浏览器。想上传自己的书（docx / txt）生成锚点与第一章预览，需输入体验码。
